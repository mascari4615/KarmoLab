## 👥 Companion Mode

### 🚀 진행 중 (Active Tasks: Companion)

- [ ] **'Companion' 네이밍 변경 고민**: 더 어울리거나 직관적인 이름 아이디에이션.
- [ ] **타이머 및 뽀모도로**: 집중 시간 관리를 위한 타이머 시스템 및 UI 구현.
- [ ] **상태 리포트**: 유휴 상태 복귀 시 부재 기간 활동 및 알람 요약 대사 출력.

### 📅 계획됨 (Planned: Companion)

- [ ] **정각 알림 (Hourly Chime)**: 매시 정각 시각 알림 기능.
- [ ] **스트레칭 알림 (Stretch Reminder)**: 장시간 연속 입력 시 휴식 권고 알림.
- [ ] **인형 메이드 AI 상호작용**: NPC 상태 대화문 연동 시스템.
- [ ] **D-Day Counter**: 중요한 날짜 머리 위에 띄워두기.
- [ ] **물리 효과 적용**: 관성 및 중력 기반 물리 상호작용.
- [ ] **Idle Chat**: 일정 시간마다 랜덤 혼잣말 시스템.
- [ ] **청소**: 화면 구석에 먼지 요정이 생김. 컴패니언을 드래그해서 먼지 요정 근처로 가져가면 청소 애니메이션 실행. 청소를 할 때마다 컴패니언의 기분 수치 상승 및 소량의 재화 획득.
- [ ] **낚시**: 마우스 커서를 화면 하단(작업 표시줄 근처)에 두면 컴패니언이 낚시대를 던짐. 시간이 지나면 물고기를 낚으며 경험치 획득.
- [ ] **농사**: 화이트보드 포스트잇 옆에 작은 '화분'을 배치. 사용자가 타이머를 완료할 때마다 물을 주어 식물을 키움. 다 자란 식물은 새로운 테마 색상이나 악세서리 제공.
- [ ] **클릭커**: 컴패니언을 연속해서 클릭하면 콤보가 쌓임. 콤보가 높을 때 특정 생산성 도구(타이머 등)의 보너스 배율 상승.
- [ ] **뽀모도로 가디언**: 타이머를 켜면 컴패니언이 '독서 중' 또는 '일하는 중' 모드로 변신. 사용자가 딴짓을 하려 하면 컴패니언이 창 앞에 나타나 집중하라며 주의를 줌. 25분 집중 후 5분 휴식 시간에는 컴패니언이 스트레칭 동작을 하며 사용자에게도 권유.
- [ ] **포스트잇 배달부**: `Project Manager`에서 설정한 마감 시간이 다가오면, 컴패니언이 해당 작업 내용이 적힌 포스트잇을 들고 직접 사용자의 마우스 커서 쪽으로 달려옴.
- [ ] **메모 걸**: 메모 들고 서있기
- [ ] **아이템 & 인벤토리**: 컴패니언이 사용자의 화면을 탐색하며 발견하는 아이템이 있으면 인벤토리에 추가됨.
- [ ] **시선 추적 (Eye Tracking)**: 마우스 커서 위치를 따라 아바타의 눈동자나 고개가 움직임.
- [ ] **쓰다듬기 (Petting)**: 마우스 커서를 아바타 머리 위에서 좌우로 빠르게 움직이면 '쓰다듬기'로 인식 -> 하트 파티클 방출.
- [ ] 환경 별 변화 (시간, 요일, 모드 등)

### ✅ 완료 (Done: Companion)

- [x] **CompanionCharacter 컴파일 에러 수정**: `UnityEditor.Animations` 참조에 전처리 가드(`#if UNITY_EDITOR`) 적용하여 빌드 에러 해결. <!-- 2026-01-24 -->

## 👥 Analyser

사용자가 주 단위의 삶을 되돌아보고, 장기적인 관점에서 삶의 질을 개선할 수 있도록 돕는 도구 지향.  

### 📅 계획됨 (Planned: Analyser)

- [ ] **활동 히트맵 (Activity Heatmap)** 태그(업무, 휴식, 학습 등)별 고유 색상을 그리드에 적용. 특정 시기별 주요 활동 변화를 한눈에 파악.
- [ ] **라이프 인사이트 (Life Insights)**: 주요 활동 패턴, 시간 관리, 스트레스 수준 등을 시각화하여 인사이트 제공.
- [ ] **라이프 밸런스 (Life Balance)**: 축을 측정하여 (업무, 건강, 재정, 관계 등) 특정 항목 편중 시 경고 메시지 제공.
- [ ] **몰입도 및 만족도 분석**: 단순히 시간의 양이 아닌 몰입의 질 측정. 산점도 등을 활용해 고효율/고만족 시간대 도출.
- [ ] **상태 트래킹**: 매일 컨디션 및 에너지를 1~5점 척도로 기록. 활동 유형과 에너지 변화 간의 상관관계 분석.
- [ ] **타임캡슐 (Time Capsule)**: 미래의 특정 주차 블록에 메시지 예약. 해당 주차가 현재가 되었을 때 내용 공개.
- [ ] **업적 시스템**: 특정 활동 목표 달성 시 배지 부여 (예: 7일 연속 규칙적 취침 등).
