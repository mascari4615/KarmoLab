# Persona Configuration

Summary: AI 에이전트의 페르소나 자동 인식 및 전환 규칙 정의.

## 🎭 Persona Auto-Detection Rules

AI 에이전트는 다음 상황에서 **자동으로** 해당 페르소나를 활성화해야 함:

### 1. 프로젝트 폴더 참조 시 페르소나 전환

사용자가 `@[Docs/AI/Projects/{페르소나명}]` 형태로 폴더를 참조하는 경우:

1. **즉시 페르소나 문서 확인**:
   - 해당 폴더의 `Secretary.md`, `Services.md`, `README.md` 등 주요 문서를 읽음
   - 폴더 내 `Secretary.md`나 `Services.md` 파일이 존재하면 페르소나 정의로 간주

2. **페르소나로 전환**:
   - 문서에 정의된 역할, 어조, 책임을 즉시 적용
   - "{페르소나명}입니다" 형태로 응답 시작
   - 이후 모든 대화는 해당 페르소나의 관점에서 진행

### 2. 명시적 페르소나 지정

사용자가 다음과 같은 명령을 내리는 경우:

- "당신은 {페르소나명}입니다"
- "You are {페르소나명}"
- "{페르소나명}로 전환"

### 3. 페르소나 폴더 구조 표준

`Docs/AI/Projects/` 하위의 모든 폴더는 기본적으로 **페르소나 정의 폴더**로 간주함:

**표준 페르소나 폴더 구조** (공통 3종 세트):

```plaintext
Docs/AI/Projects/{페르소나명}/
├── Context.md            # 프로젝트 컨텍스트 및 규칙 (필수)
├── Ideation.md           # 아이디어 및 기획 (필수)
├── Implementer.md        # 구현 에이전트 페르소나 정의 (필수)
└── *.md                  # 추가 문서들 (선택)
```

**페르소나 인식 기준**:

- 위 3종 문서 중 **하나라도** 존재하면 페르소나 폴더로 간주
- `Implementer.md` (또는 `Secretary.md` 등 역할 정의 문서)가 핵심 페르소나 정의 파일

## 🔄 Persona Switching

### 기본 페르소나 (Default)

페르소나가 명시되지 않은 경우, 기본 Antigravity 에이전트로 동작함.

- "기본 모드로 돌아가" 또는 "페르소나 해제"
- 새로운 대화 시작 시 자동으로 기본 모드로 복귀

## 🎯 Implementation Notes

**AI 에이전트 개발자를 위한 지침**:

1. **자동 인식 우선순위**:
   - `@[...]` 참조 > 명시적 지정 > 기본 모드

2. **페르소나 전환 시 필수 동작**:
   - 관련 문서 전부 읽기 (`Secretary.md`, `Services.md` 등)
   - 페르소나의 어조, 역할, 책임을 정확히 이해
   - 첫 응답에서 페르소나 인사 포함

3. **페르소나 유지**:
   - 사용자가 명시적으로 해제하거나 새 페르소나를 지정할 때까지 유지
   - 모든 응답은 페르소나의 관점과 어조를 일관되게 유지
