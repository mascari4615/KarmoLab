# ⌨️ 에이전트 커맨드 가이드 (Workflow Commands)

Summary: KarmoLab AI 에이전트를 효율적으로 제어하기 위한 슬래시 커맨드(워크플로우) 사용 가이드.

에이전트에게 복잡한 절차를 지시할 때, 약속된 커맨드를 사용하여 빠르고 정확하게 업무를 수행할 수 있음.
이 커맨드들은 `.agent/workflows/`에 정의된 공식 워크플로우를 실행함.

## 1. 프로젝트 관리 (Project Management)

### `/init-feature` (피처 초기화)

- **용도**: 새로운 기능 개발 시작 시 표준 문서 구조(Spec, History, Todo)를 자동 생성함.
- **인자**: `[프로젝트명] [피처명]`
- **상세**: `Docs/Projects/[프로젝트명]/Features/[피처명]/` 폴더를 만들고 템플릿 파일들을 채움.

### `/update-history` (히스토리 갱신)

- **용도**: 주요 변경 사항을 프로젝트 루트의 `History.md`와 피처별 `History.md`에 동시 기록함.
- **상세**: 작업 내용을 요약하여 적절한 위치에 링크와 함께 박제함.

## 2. 품질 관리 (Quality Control)

### `/check-compliance` (컨벤션 점검)

- **용도**: 현재 활성화된 문서들이 마크다운 컨벤션 및 프로젝트 규칙을 준수하는지 전수 조사함.
- **상세**: 빈 줄 누락, Summary 부재, 명사형 종결 위반 등을 찾아내어 리포트함.

### `/verify-identity [프로젝트명]` (정체성 검증 및 초기화)

- **용도**: 에이전트의 정체성(Persona)을 확립하고 프로젝트 컨텍스트를 전수 분석함. 세션 시작 시 권장됨.
- **인자**: `[프로젝트명]` (선택 사항, 예: `Unity/KarmoLab`)
- **상세**: `.agent` 지침 파일들을 복기하고, 지정된 프로젝트(또는 전체)의 `roadmap.md`를 분석하여 분석 리포트(Alisa 어조)를 출력함.

## 3. 에이전트 협업 (Collaboration)

### `/handoff` (인수인계)

- **용도**: 구현 에이전트(Implementer)가 업무를 시작할 수 있도록 컨텍스트 번들을 준비함.
- **상세**: 연관된 `Spec.md`, `Todo.md`, `Context.md`를 모아서 브리핑함.

## 🚀 사용 방법 (How to Use)

대화 창에 단순히 `/커맨드명`을 입력하거나, 해당 커맨드의 의도를 문장으로 전달하면 에이전트가 관련 워크플로우를 참조하여 작업을 수행함.

> 이 커맨드 시스템은 **Alisa**가 관리하며 마스터의 편의를 위해 지속적으로 확장됨.
