# WM 세계

운도, 가마, 한울의 세계 지도와 행성 편집기. 같은 높이, 생물군계 데이터를 평면 지도와 구면에 투영한다. 완성된 지도 이미지를 행성에 붙이지 않는다.

## 실행

이 폴더에서 실행:

```sh
npm ci
npm run dev
```

로컬 주소는 `http://127.0.0.1:8874/atlas/`.

검사와 정적 빌드:

```sh
npm test
npm run build
```

## 편집과 저장

- `세계 편집`에서 행성 생성, 복제, 높이와 생물군계 칠하기, 장소 기록, 실행 취소, 다시 실행.
- 행성에서 회전은 카메라 이동이다. 가마를 향한 방향과 낮, 밤은 행성에 고정된다.
- 편집 도구를 접어도 선택한 붓은 유지된다. 지도와 행성에서 붓의 범위 확인 가능.
- IndexedDB에 행성별 자동 저장. 예전 localStorage 저장본도 읽는다. JSON 내보내기, 불러오기는 별도 사본으로 보관.
- 브라우저 저장은 기기 사이에 동기화되지 않는다. 옮기거나 보관할 때 JSON 내보내기를 사용한다.

## 구성

- `source-coasts.mjs`: 손그림에서 옮긴 해안 좌표.
- `landform.mjs`: 높이 생성과 침식. 생성 worker에서 실행.
- `fields.mjs`, `atlas.mjs`, `planet.mjs`: 숫자 배열을 GPU로 전달하고 지도, 행성 렌더.
- `hydrology.mjs`, `weather-field.mjs`: 파생 배수선과 구름 수치장. 별도 worker에서 계산.
- `terrain.mjs`, `editor.mjs`, `storage.mjs`: 편집, 구면 보간, 저장, 복구와 파일 검증.

신규 지형은 768×432, 기존 256×144 JSON도 지원한다. 지도 사진의 범위가 행성 전체인지, 실제 위경도, 거리와 미확정 지명은 세계관 확정 사항이 아니다. 생성한 산줄기, 배수선, 구름은 편집 가능한 잠정 표현이다.

2026-11-18 검증: 관련 테스트17개와 build 통과. FHD, QHD, 390×844에서 표시 검토, 새 행성, JSON 왕복, 복원 조작 확인. 성능 계측은 `#stage`의 data 속성에서 조작 구간의 프레임 분포와 긴 작업을 확인한다. 수치는 검증한 PC의 짧은 조작 구간이며 모든 기기의 성능을 보장하지 않는다.

## 배포

`https://wm.mascari4615.com/atlas/` 전용 정적 앱. 기존 WM 게임의 루트와 서버 연결은 유지한다. `wrangler.toml`의 경로와 Vite의 base를 함께 유지해야 한다.

`Deploy WM atlas` workflow는 이 앱 변경 시 테스트와 빌드 후 정적 파일을 배포한다. 인증은 저장소의 `CLOUDFLARE_API_TOKEN`을 사용하며 브라우저 앱에는 포함하지 않는다.

Noto Sans KR, Noto Serif KR의 라이선스는 `public/fonts/*-OFL.txt`에 포함한다. 원본 지도는 직접 그린 그림이다.
