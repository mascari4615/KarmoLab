# KarmoDevExtension

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

사용자 본인의 Edge 브라우저. 아카라이브에서 팔로우한 작성자의 글 탐색.

## Product Purpose

사용자의 로그인된 페이지와 확장에 저장된 목록을 연결. 팔로우 글 페이지는 채널 구분 없이 작성자를 기준으로 최근 글 병합.

## Capabilities and Constraints

기존 `likelist.arca`가 팔로우 정본. 계정은 `닉#번호`, 고정닉은 고유 닉으로 구분. 채널 목록 등록 불필요. 사이트 프로필이 공개하는 최근 작성글 범위만 수집. 비공개, 삭제, 접근 제한의 복구 불가.

## Operating Context

확장 팝업과 아카라이브 설정에서 전용 탭 열기. 기존 아카라이브 글에서 팔로우 등록. 사용자 요청 2026-10-14, 작성자 관심 등록의 용어를 좋아요에서 팔로우로 변경.

## Open Decisions

전체 과거 글 검색과 예약 수집은 이번 범위 밖.

## Blocking

아카라이브 목록의 작성자 일반 차단과 즉시 완전 차단, 원문 채널 차단. breaking과 검색의 가상 주소는 글의 canonical로 실제 채널을 확인한 뒤 적용. 차단 직후 되돌리기, 게시판 상단의 검색 가능한 차단 관리에서 현재 페이지에 없는 항목도 해제.

사용자가 기준 채널을 지정하면 해당 채널 글에서 만난 작성자와 공개 최근 작성글에 그 채널 이력이 있는 작성자를 자동 완전 차단. 기본 규칙은 빈 목록. 전체 과거 이력을 수집하지 않으며, 실패한 조회는 일치 또는 불일치로 확정하지 않음. 자동 차단을 직접 해제하면 예외로 보관. 규칙 삭제는 자동 항목을 해제하고 원래 수동 차단이 있으면 복원.
