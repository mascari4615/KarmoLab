# KarmoDevExtension

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

사용자 본인의 Edge 브라우저. 아카라이브에서 좋아요한 작성자의 글 탐색.

## Product Purpose

사용자의 로그인된 페이지와 확장에 저장된 목록을 연결. 좋아요 글 페이지는 채널 구분 없이 작성자를 기준으로 최근 글 병합.

## Capabilities and Constraints

기존 `likelist.arca`가 좋아요 정본. 계정은 `닉#번호`, 고정닉은 고유 닉으로 구분. 채널 목록 등록 불필요. 사이트 프로필이 공개하는 최근 작성글 범위만 수집. 비공개, 삭제, 접근 제한의 복구 불가.

## Operating Context

확장 팝업과 아카라이브 설정에서 전용 탭 열기. 기존 아카라이브 글에서 좋아요 등록.

## Open Decisions

전체 과거 글 검색과 예약 수집은 이번 범위 밖.
