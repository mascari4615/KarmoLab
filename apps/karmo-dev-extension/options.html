같은 유저의 글 구분

한 페이지에 두 줄 이상 쓴 유저를 유저마다 다른 색으로 보입니다. 닉네임은 색 알약, 줄 왼쪽에 색 띠.

색

자동 색은 아래 팔레트에서 유저마다 하나씩 고릅니다. 한 페이지에서 겹치지 않게 다음 칸으로 넘어갑니다.

유저별로 지정한 색 (왼쪽 패널에서 바꾼 것)

    차단

    차단한 유저의 글은 숨기고 페이지 맨 아래 블록에 모읍니다. 아래 조건이면 숨기지 않고 "차단됨" 표시로 보입니다.

    인사이트 (왼쪽 패널)

    좋아요 유저 최근 글, 최근 작성량, 취향 제안 (차단 후보와 좋아요 후보) 을 왼쪽 패널에 보입니다. 확장이 같은 보기의 앞쪽 글 목록을 직접 받아 읽고 (10분에 한 번), 내가 연 글과 본 글 수를 유저별로 쌓습니다.

    키워드 숨김

    제목에 이 단어가 들어 있는 글을 숨깁니다 (한 줄에 하나, 대소문자 무시, re: 로 시작하면 정규식). 숨긴 글은 차단 글과 같이 페이지 맨 아래 블록에 모이고 거기서 "키워드 빼기"로 풀 수 있습니다.

    차단, 좋아요 목록

    글 줄에 마우스를 올리면 나오는 ♥ (좋아요) 와 × (차단) 로 추가합니다. 바뀔 때마다 다운로드 폴더의 karmo-userlists/userlists.json 에 자동으로 덮어쓰고, 작업 스케줄러의 publish 스크립트가 바뀐 때만 memo 의 userlists-data 브랜치에 커밋합니다.
