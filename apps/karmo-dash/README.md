# KarmoDash PC

- Windows 앱. 캘린더, 오늘 할 일, 다음 일정과 개인 대시보드.
- 기존 Dash 웹 화면을 전용 WebView2 창에서 표시. 인터넷 연결 필요.
- 메뉴의 `브라우저 연결 가져오기`: 기본 브라우저에서 기존 로그인, 구글 연결, 로컬 일정 복사 확인. 브라우저의 원본 유지. 가져오기는 한 번만, 이후 로컬 일정은 앱과 브라우저에서 별도 저장.
- 닫기는 트레이로, 열기와 끝내기는 트레이 메뉴. 두 번째 실행은 기존 창 표시. `--quit`로 종료.
- 디스코드 알림은 연결한 서버에서 계속 수집. PC 앱 종료와 독립.
- 설치와 업데이트는 Karmo Launcher. 앱 자체 업데이터 없음.
- `npm ci`, `npm run build`. 검사 `npm test`.
