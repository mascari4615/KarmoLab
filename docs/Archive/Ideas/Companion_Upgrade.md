# 💡 Companion 기능 고도화 아이디어

`CompanionFeature`의 현재 구현(투명 윈도우, 기본 드래그)을 기반으로, 사용자와 더 깊이 교감하고 실질적인 도움을 줄 수 있는 **'살아있는 데스크탑 파트너'**로 발전시키기 위한 제안임.

## 1. Context Aware (상황 인식 시스템)

단순히 화면 위에 떠있는 것이 아니라, 사용자의 환경과 상태를 인식하여 반응함.

- **작업 집중 모드 감지**: 키보드/마우스 입력 빈도를 분석하여, 사용자가 열심히 타이핑 중일 때는 방해하지 않도록 구석으로 이동하거나 조용히 응원하는 애니메이션 재생.
- **시간대별 루틴**:
  - **아침**: "좋은 아침!" 인사와 함께 오늘 할 일(`QuestBoard` 데이터) 요약 표시.
  - **점심/저녁**: 식사 시간 알림 아이콘 띄우기.
  - **심야**: "너무 늦었어요"라며 졸린 표정 짓기.
- **실제 날씨 연동**: 외부 날씨 API와 연동하여 비가 오면 우산을 쓰거나, 추우면 떨게 만들기.

## 2. Emotional System (데이터 기반 감정)

`KarmoToysData`의 다른 기능들과 데이터를 공유하여 컴패니언의 기분을 결정함.

- **할 일(Todo) 달성률**: 오늘 계획된 `Quest`를 많이 완료하면 기쁨(Happy) 상태, 밀리면 걱정(Worry) 상태.
- **비밀 노트(Note)**: 최근 작성한 `SecretNote`의 감정 분석(긍정/부정 단어)에 따라 위로 모드 작동.
- **호감도 시스템**: 자주 쓰다듬어주거나(마우스 비비기), 클릭해주면 친밀도 상승. 친밀도가 높으면 특별한 대사나 선물(숨겨진 기능 해금) 제공.

## 3. Interactive Actions (상호작용 확장)

단순 드래그를 넘어선 물리적/감성적 상호작용 추가.

- **쓰다듬기 (Petting)**: 마우스 커서를 아바타 머리 위에서 좌우로 빠르게 움직이면 '쓰다듬기'로 인식 -> 하트 파티클 방출.
- **들기 (Picking up)**: 드래그 시 아바타가 매달리는 애니메이션 재생 (현재는 위치만 이동됨). 놓았을 때 가볍게 착지하는 물리 효과.
- **시선 추적 (Eye Tracking)**: 마우스 커서 위치를 따라 아바타의 눈동자나 고개가 움직임.

## 4. Utility Integration (비서 기능)

귀여움 뿐만 아니라 유용함까지 챙기기.

- **포스트잇 배달부**: `Dashboard`에 적힌 중요한 메모를 아바타가 들고 서있게 하기.
- **뽀모도로 타이머**: 집중 시간 동안 아바타가 공부/일하는 모습으로 변신, 휴식 시간에는 스트레칭 권유.
