# Tech Note: Smart Backup Algorithm

사용자 작업 흐름 방해 없이 데이터 안전성 확보를 위한 **지능형 백업 시스템** 설계.

## 1. 핵심 컨셉
단순 "저장 시 백업"은 디스크 낭비, "시간 단위 백업"은 중요 시점 누락 위험 존재.
따라서 **"유의미한 변경 누적 시"** 백업하는 전략 사용.

## 2. 변경 감지 알고리즘 (Change Detection)

### 정밀 감지 (Deep Detection)
단순 파일 크기/시간 비교가 아닌, 데이터 모델 수준의 변경 사항을 가중치(Score)로 계산.

- **Threshold (임계값)**: 백업을 트리거하는 변경 점수 (기본값: 10점)
- **Scoring Rules**:
    - **중요 변경 (5점)**: 항목 생명주기 변화 (생성/삭제).
    - **일반 변경 (2점)**: 핵심 데이터 수정 (TimeBlock 시간 변경, Todo 완료).
    - **사소한 변경 (1점)**: 단순 텍스트 수정 (오타 수정 등).

### 누적 추적 (Cumulative Tracking)
일반 저장과 달리 **'마지막 백업'** 시점의 스냅샷과 현재 상태 비교.

> **Scenario**:
> 1. 오타 수정 (1점) -> 저장 (백업 안 함)
> 2. 태그 수정 (1점) -> 저장 (백업 안 함)
> 3. ... 반복 ...
> 4. 누적 점수 10점 도달 -> **자동 백업 수행**

## 3. 트리거 시점 (Triggers)
1. **App LifeCycle**: 앱 실행(Start) 및 종료(Quit) 시에는 점수와 무관하게 무조건 백업 (안전장치).
2. **On Save**: 수동/자동 저장 시 변경 점수 체크 후 조건부 백업.

## 4. 중복 방지 (Deduplication)
백업 생성 직전 데이터 해시(MD5/SHA) 계산, 최근 백업과 내용 100% 일치 시 백업 스킵. "변경 사항 없음" 감지용 최후 보루.
