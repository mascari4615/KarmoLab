# Maintainer's Collaboration Guide (메인테이너 협업 가이드)

Summary: 프로젝트 메인테이너가 AI 에이전트를 효율적으로 활용하고 프로젝트를 안전하게 관리하기 위한 지침.

## 1. 🗣️ 스마트한 명령 내리기 (Smart Commanding)

에이전트에게 최상의 결과물을 뽑아내기 위한 **황금 프롬프트** 예시입니다:

```text
@[Docs/AI/Projects/KarmoAI] 여기 읽고 너의 페르소나 파악해줘. // 1.1 컨텍스트 명시 (@ 참조)
새로운 피처인 'Gemini_Integration'을 구현하려고 해. // 1.2 목표 명확화
먼저 Features 하위에 Spec, History, Todo 문서를 작성해. // 1.3 Documentation First 강제
그 다음 KarmoAI.csproj에 Gemini API 패키지를 추가하고, // 1.4 작업 단계 세분화
작업이 끝나면 /review-work 워크플로우로 스스로 검토해줘. // 1.5 검증 자동화 요청
```

- **1.1 컨텍스트 명시**: 에이전트가 어떤 지침과 배경 지식을 가지고 작업해야 하는지 `@[경로]`를 통해 확실히 알려주세요.
- **1.2 목표 명확화**: 어떤 '기능(Feature)'을 만드는 중인지 이름을 명확히 알려주면 폴더 구조 가이드가 쉬워집니다.
- **1.3 Documentation First**: 코드를 작성하기 전에 문서를 먼저 쓰라고 지시하는 것이 KarmoLab의 철칙입니다.
- **1.4 작업 단계 세분화**: 한 번에 다 시키지 말고, "패키지 추가 -> 코드 구현" 식으로 단계를 나눠주는 것이 좋습니다.
- **1.5 검증 자동화**: 작업이 끝나면 에이전트가 스스로 검토 워크플로우를 실행하게 하여 실수를 방지합니다.

## 2. 🌲 Git & 히스토리 관리 (Git Strategy)

- **1 Feature = 1 Branch**: 가급적 새로운 기능은 전용 브랜치(`feat/feature-name`)에서 작업하고, 테스트 완료 전까진 `main`에 병합하지 마세요.
  - **네이밍 규칙**: `feat/기능명`, `fix/버그명`, `refactor/대상`, `docs/문서명`
- **단일 책임 커밋 (Single Responsibility Commit)**: "1기능 1커밋" 원칙을 지켜주세요.
  - ❌ `기능 A 구현하고 B도 고치고 문서도 수정함` (나중에 추적 불가)
  - ✅ `feat: 기능 A 구현`, `fix: B 버그 수정`, `docs: README 업데이트` (깔끔하고 추적 용이)
- **AI에게 커밋 메시지 위임**: 작업 내용을 AI가 알고 있으므로, `!commit` 명령어로 "이 작업 요약해서 커밋 메시지 써줘"라고 시키면 포맷에 맞춰서 작성해줍니다.
  - 예: `git commit -m "feat: add user secrets configuration"`
- **작업 전 상태 확인 (Git Status Check)**: AI에게 작업을 지시하기 전 항상 `git status`를 확인해서 로컬 변경사항이 없는 '깨끗한 상태'인지 확인해주세요. 충돌을 방지할 수 있습니다.

## 3. 🔍 검토 및 피드백 (Review & Feedback)

- **`/review-work` 활용**: 에이전트가 작업을 마쳤다고 하면 바로 코드를 보지 말고, 워크플로우로 먼저 검증을 요청하세요.
- **TC(Test Case) 직접 수행**: 에이전트가 작성해온 TC를 보고 직접 '플레이 테스트'를 해보는 것이 가장 확실합니다. "안 되는데?"라고 하기보다 "TC 3번에서 이런 에러가 나"라고 구체적으로 피드백해주세요.
- **설계 우선 원칙**: 코드가 마음에 안 들면 코드부터 고치라고 하지 말고, `Spec.md`의 설계부터 다시 잡으라고 지시하세요.

## 4. 🚀 요약 체크리스트 (Summary)

- [ ] 관련 컨텍스트를 `@[...]`로 제공했는가?
- [ ] 설계 문서(Spec/History/Todo) 작성을 명령했는가?
- [ ] 작업 단위가 쪼개져 있는가?
- [ ] 작업 완료 후 `/review-work`를 수행했는가?
- [ ] 메인테이너가 직접 플레이 테스트를 완료했는가?
