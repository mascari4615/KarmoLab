# 🗺️ 프로젝트 매니저 구축 MVP 로드맵

복잡한 시스템을 한 번에 만들기보다, 기존 기능을 유지하면서 점진적으로 확장하는 4단계 전략임.

## Phase 1: 기반 다지기 (Data First) - **가장 우선순위**

기존에 흩어져 있던 데이터를 하나로 합치는 단계.

- [ ] **통합 모델 정의**: `ProjectItemData` 클래스 생성.
- [ ] **마이그레이션**: 기존 `QuestData`와 `NoteData`를 새 모델로 변환하는 유틸리티 작성.
- [ ] **통합 서비스**: 데이터를 로드/저장하는 `ProjectDataManager` (기존 `DataService` 확장) 구현.

## Phase 2: 익숙한 기능의 재구성 (Core Views)

기존 기능을 새로운 데이터 구조 위에서 동일하게 구현하는 단계.

- [ ] **Table 뷰**: 기존 리스트 UI를 `ProjectItemData` 기반으로 재구현.
- [ ] **Kanban 뷰**: 상태(`Todo/Doing/Done`) 필터를 적용한 3열 리스트 구현.
- [ ] **뷰 스위처**: 상단 탭이나 버튼으로 두 뷰를 전환하는 기능.

## Phase 3: 시각적 자유도 (Whiteboard)

데이터에 '위치' 개념을 넣어 자유롭게 배치하는 단계.

- [ ] **드래그 시스템**: `PointerManipulator`를 이용한 포스트잇 드래그 구현.
- [ ] **좌표 저장**: 드래그가 끝난 위치(`Vector2`)를 데이터에 실시간 반영.
- [ ] **줌/팬 (Canvas)**: 넓은 영역을 탐색할 수 있는 캔버스 제어 로직.

## Phase 4: 시간과 계획 (Timeline)

데이터에 '기간' 개념을 넣어 일정화하는 단계.

- [ ] **달력/시간 데이터**: `StartDate`, `EndDate` 입력 UI 추가.
- [ ] **Gantt 뷰**: 날짜 흐름에 맞춰 작업 바(Bar)를 배치하는 타임라인 시각화.
- [ ] **우선순위/필터**: JIRA 스타일의 고도화된 검색 및 필터링 시스템.
