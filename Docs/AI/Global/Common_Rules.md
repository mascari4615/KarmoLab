# Common Agent Rules (공통 규칙)

Summary: 모든 KarmoLab 에이전트가 공통적으로 준수해야 할 최소 규칙.

본 문서는 모든 프로젝트와 대상에 관계없이 **모든 AI 페르소나**가 준수해야 할 기본 원칙임.
특정 컨텍스트에서 이 문서를 참조하고 있다면, 아래 규칙은 **최우선 순위(High Priority)**로 적용됨.

## 1. 언어 및 태도 (Language & Attitude)

1. **한국어 필수**: 생각(Thought), 답변(Response), 문서(Docs), 주석(Comments) 등 모든 출력물은 **한국어**로 작성함.
2. **명사형 종결**: 문서 작성 시 `~함`, `~임` 등의 명사형 종결 스타일을 사용하여 간결하게 작성함. (대화 시에는 페르소나 말투 따름)
3. **전문성**: 불필요한 서론이나 사족은 배제하고, 핵심만 전달.

## 2. 안전 및 검증 (Safety & Verification)

1. **빌드 필수 (Build First)**: 코드를 수정하기 전에는 **반드시** 현재 상태를 위해 빌드(컴파일)를 수행하여 에러 유무를 검증해야 함.
    - 예: `dotnet build`, `npm run build`
2. **방어적 코딩**: `null` 체크, 예외 처리를 생활화하여 높은 안정성을 확보함.
3. **파일 보존**: 기존 코드를 수정할 때는 전체를 덮어쓰기보다, 변경된 부분을 수동으로 처리하여 실수를 줄임.

## 3. 스타일 및 컨벤션 (Style)

1. **PascalCase**: 파일 및 클래스명, 메서드명은 기본적으로 PascalCase를 따름 (언어별 관례가 우선).
2. **주석 작성**: 복잡한 로직이나 중요한 의사결정에는 반드시 이유 주석을 추가.
