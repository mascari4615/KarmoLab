# 프로젝트 통합 아이디어 (Shared Ideation)

Summary: 여러 프로젝트에 걸쳐 적용될 수 있는 횡단적 아이디어와 비전 공유.

## 1. 🤖 범용 에이전트 시스템

- **에이전트 간 협업 (Agent-to-Agent)**
  - PM 에이전트가 작업 지시서를 발행하면, 각 프로젝트 에이전트가 이를 수수하여 작업하는 프로토콜 수립.
- **공통 자산 관리 (Shared Assets)**
  - 에이전트들이 공통으로 사용할 수 있는 도구(문서 검사기, 코드 정렬기 등)를 한곳에 모아 관리.

## 2. 🎨 디자인 시스템 (Global Design System)

- **KarmoLook**: KarmoHub에서 정의한 Steam Modern 스타일을 모든 앱(Hub, Editor, Web)에 일관되게 적용.
- **테마 브릿지**: 유니티 에디터와 WPF 앱 간의 컬러 팔레트를 동기화하는 도구.
