# 🌐 Global AI Resources

Summary: 모든 프로젝트에 공통으로 적용되는 AI 규칙 및 협업 가이드라인.

이곳은 KarmoLab의 모든 AI 에이전트가 공유하는 두뇌와 같은 공간임.

## 📋 주요 문서 (Core Docs)

- **[Common_Rules.md](Common_Rules.md)**: 모든 에이전트가 지켜야 할 절대 원칙 (언어, 보안, 스타일).
- **[Roster.md](Roster.md)**: 현재 프로젝트에 투입된 AI 에이전트 팀 명단.
- **[Backlog.md](Backlog.md)**: 전체 프로젝트 통합 작업 대기열.
- **[Workflow_Commands.md](Workflow_Commands.md)**: 에이전트를 지시하는 명령어(슬래시 커맨드) 가이드.

## 🛠️ 협업 프로세스

1. 마스터(사용자)가 작업을 지시함.
2. Alisa(PM)가 설계를 진행하고 구체적인 작업 지시를 내림.
3. 담당 Implementer 에이전트가 지침을 받아 구현을 수행함.
