# KarmoHub 아이디어 (Ideation)

Summary: KarmoHub 런처 프로젝트의 UI/UX 및 시스템 기능 개선 아이디어.

## 1. UX/UI 개선

- **데스크톱 위젯 (Desktop Widgets)**
  - 런처를 켜지 않아도 바탕화면에서 다운로드 상태나 선호하는 게임의 커뮤니티 소식을 확인.
- **트레이 미니 제어판**
  - 시스템 트레이 아이콘 우클릭 메뉴에서 게임 즉시 실행 및 볼륨 조절.

## 2. 기능 확장

- **다운로드 매니저 고도화**
  - 대역폭 제한 설정 및 예약 다운로드 기능.
- **피드 시각화**
  - GitHub 외에도 마스터의 SNS 소식이나 커뮤니티 공지 연동.
