# Core Concept: Life Dashboard

사용자의 100세 인생(5,200주) 시각화 및 데이터 분석 아이디어 정리.

## 1. 핵심 컨셉

- **시간의 유한함 시각화**: 100세 인생을 5,200개의 점으로 표현하여 시간의 흐름을 직관적으로 체감.
- **주차별 기록**: 매주(week)를 색상이나 태그로 기록하여 인생 전체를 조망하는 히트맵 생성.

## 2. 주요 시각화 요소

### 2.1. 인생 그리드 (Main Grid)

- **구성**: 100행(나이) × 52열(주차) 그리드.
- **상태 구분**:
  - **과거 (Lived)**: 지나온 시간을 검은색 또는 특정 색상으로 표시.
  - **현재 (Current)**: 현재 주차를 강조 표시(하이라이트 또는 애니메이션).
  - **미래 (Future)**: 남은 시간을 무채색으로 표시하여 기대감 조성.
- **레이아웃**: PC 환경에 최적화된 가로형 배치 및 모던한 디자인 적용.

### 2.2. 활동 히트맵 (Activity Heatmap)

- **구현**: 태그(업무, 휴식, 학습 등)별 고유 색상을 그리드에 적용.
- **목적**: 특정 시기별 주요 활동 변화를 한눈에 파악.

## 3. 분석 및 통계 기능

### 3.1. 라이프 밸런스 (Life Balance)

- **지표**: 업무, 건강, 관계, 수면, 성장, 재미 등 6개 축 측정.
- **피드백**: 특정 항목 편중 시 사용자 알림 제공.

### 3.2. 몰입도 및 만족도 분석

- **지표**: 단순히 시간의 양이 아닌 몰입의 질 측정.
- **시각화**: 산점도 등을 활용해 고효율/고만족 시간대 도출.

### 3.3. 상태 트래킹

- **기록**: 매일 컨디션 및 에너지를 1~5점 척도로 기록.
- **인사이트**: 활동 유형과 에너지 변화 간의 상관관계 분석.

## 4. 인터랙션 및 게이미피케이션

### 4.1. 타임캡슐 (Time Capsule)

- **기능**: 미래의 특정 주차 블록에 메시지 예약.
- **해제**: 해당 주차가 현재가 되었을 때 내용 공개.

### 4.2. 업적 시스템

- **기능**: 특정 활동 목표 달성 시 배지 부여 (예: 7일 연속 규칙적 취침 등).

### 4.3. 과거 비교 (Comparison)

- **기능**: 현재 데이터를 과거(전월, 전년 등) 데이터와 반투명하게 겹쳐서 비교.
- **목적**: 시기별 활동 패턴 변화 및 성장 확인.

## 5. 어시스턴트 기능 (AI Integration)

### 5.1. AI 분석 리포트

- **기능**: Gemini AI 기반 주간 분석 리포트 발행.
- **내용**: 데이터 기반의 생활 패턴 분석 및 최적화 제안.

### 5.2. 인터랙티브 피드백

- **상태 동기화**: 사용자 데이터에 따라 어시스턴트의 반응 변화.
- **알림**: 몰입 모드 지원, 랜덤 영감이 담긴 질문 던지기 등.

## 6. 목표

사용자가 주 단위의 삶을 되돌아보고, 장기적인 관점에서 삶의 질을 개선할 수 있도록 돕는 도구 지향.
