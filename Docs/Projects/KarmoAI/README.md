# Project: KarmoAI (README)

Summary: KarmoLab 통합 AI 서비스 레이어 프로젝트 개요.

## 1. 개요 (Overview)

- **목적**: KarmoLab 생태계 내의 모든 에이전트와 애플리케이션에 지능형 AI 기능을 제공함.
- **핵심 가치**: 독립성, 확장성, 경량화.

## 2. 주요 기능

- **LLM Gateway**: 다중 모델(Gemini 등) 통합 인터페이스.
- **Context Manager**: 애플리케이션별 세션 및 컨텍스트 관리.
- **Data Extractor**: 비정형 텍스트를 정형 데이터(JSON)로 변환.

## 3. 기술 스택

- **Platform**: .NET
- **Version**: 1.0.0-alpha (기획 단계)
