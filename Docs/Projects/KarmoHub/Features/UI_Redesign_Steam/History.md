# UI 리디자인 히스토리

Summary: KarmoHub UI 리디자인 작업의 상세 구현 역사.

## 2026-01-19 (KST)

### 주요 변경 사항

- **테마 시스템 구축**: Dark, Monochrome, Light 테마 전수 구현 완료.
- **컴포넌트 리디자인**:
  - 메인 윈도우 배경에 히어로 그라데이션 적용.
  - 테마 전환 방식을 토글 버튼에서 콤보박스로 고도화.
  - 각 테마별 텍스트 가독성 최적화 (Light 모드 폰트 컬러 조정).

### 결정 사항 (Decision Log)

- **Obsidian 테마 기본화**: 사용자 경험 통계(가상)와 마스터의 선호도를 반영하여 Obsidian 테마를 기본값으로 설정.
- **Glassmorphism 제한적 사용**: 성능 저하 방지를 위해 메인 헤더와 카드 요소에만 선택적으로 블러 효과 적용.
