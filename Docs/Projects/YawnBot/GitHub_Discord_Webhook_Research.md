# GitHub & Discord Webhook Research

디스코드 봇을 통해 깃허브 상황을 확인하고 생산성을 높이기 위한 조사 결과임.

## Summary

- **웹훅 개념**: 깃허브-디스코드 연동 방식(직접 연동 vs 봇 미들웨어) 비교함.
- **서버 분석**: 업계 표준(DigitalOcean, Vultr) vs 대기업(AWS) 비교 분석함.
- **예산 검토**: 10,000원 예산의 충분성 확인함.

## 1. 10,000원 예산 충분성 (Sufficiency Verdict)

"전혀 작지 않음. 개인 개발자에겐 **'완벽한 표준'** 예산임."

### 1.1. 기술적 분석

- **메모리(RAM)**: 소규모 봇은 50~200MB 사용. 1GB는 봇 3~5개 구동 가능함.
- **트래픽(Bandwidth)**: 텍스트 기반 봇은 월간 수 GB면 충분. 대부분 1TB 제공하므로 걱정 없음.
- **확장성**: `Minimal API` 웹 서버 추가해도 리소스 소모 미미함.

### 1.2. 결론

- **10,000원**은 "겨우 돌아가는 수준"이 아닌 **"쾌적하고 빠른"** 예산임.
- 엔터프라이즈급 아니면 충분함.

## 2. 서버 선택지 비교

### 2.1. 엔터프라이즈 (The Big 3)

- **AWS Lightsail ($7)**: AWS 안정성 + 고정 가격. 추천함.
- **AWS EC2 / Azure**: IP 비용 등 숨겨진 비용 발생 위험 있음.

### 2.2. 업계 표준 (DigitalOcean vs Vultr)

| 항목 | DigitalOcean | Vultr |
| :--- | :--- | :--- |
| **한국 리전** | 없음 (일본/싱가포르) | **있음 (서울)** |
| **Ping** | 70~90ms (미세한 지연) | **1~10ms (즉각 반응)** |
| **장점** | UI 깔끔, 문서 완벽함 | 가성비 좋음, 서울 리전 |
| **단점** | 한국 접속 시 딜레이 | UI 투박함, 고객지원 느림 |
| **최저가** | $4 | $2.5 (IPv6) / **$6** |

### 2.3. 최종 결론

- **Vultr (서울 리전)**: **$6 (약 8,400원)**. 빠르고 합리적임.
- **AWS Lightsail**: **$7**. AWS 브랜드 선호 시 선택.
- **Oracle Cloud**: **0원**. 무료 티어 가능 시 추천.
