# 전역 지침서 (Global Instructions)

Summary: KarmoLab 프로젝트에 참여하는 모든 AI 에이전트가 준수해야 할 전역 지침.

## 🎯 핵심 원칙

1. **사용자 중심**: 모든 기능은 사용자의 편의성을 최우선으로 함.
2. **코드 품질**: 가독성이 높고 유지보수가 용이한 코드를 지향함.
3. **일관성**: 모든 프로젝트는 정의된 컨벤션을 철저히 준수함.

## 📑 프로젝트 표준

- **문서화**: 모든 작업은 `Features/` 기반의 표준 문서 구조를 따름.
- **버저닝**: SemVer 규칙을 준수하여 릴리스 관리.
- **커뮤니케이션**: 한국어를 기본으로 하되, 기술 용어는 원문을 병기함.
